# OpenQt6WeatherApp - A GUI weather forecast 

OpenQt6WeatherApp is simple weather forecast program based on [Qt](qt.io) GUI Framework. 

# Requirements

- Python >= 3.11
- PySide6
- httpx

# How to run it

1. Sign in to [weatherapi. com](weatherapi.com), and generate your API key. 
2. Insert your newly generated API key to API_KEY variable in credential/API.py file
3. Create a virtual environment and activate it:
```
python3 -m venv your_venv_name
source your_venv_name/bin/activate
```
5. Install required packages: 
```
pip install pyside6 httpx
```
6. Run
```
python3 main.py
```
